# Independent review of the new theorems (paper2/main.tex: Sec. "An exact algorithm for one goal" and Sec. "Statistical consistency")

Scope: Theorems closed-form policy, exact estimation for fixed alpha, certified search over alpha, consistency, and the Monte Carlo paragraph; code/exact_k1.py and code/consistency_mc.py. Notation: z = alpha x, u = z - e+, l = z - e-, u <= l.
Checks are in /tmp/review2/ (t1.py ... t7.py, numpy/scipy).

Bottom line: the mathematics is essentially correct and the code implements it correctly (no counterexample found in about 2,400 closed-form checks and 300 exact-estimator instances, including ties, zero and negative D). The defects are in how the statements are written (candidate sets for the lower part, the omega-bar bound), in a loose citation for the stationary-ergodic ULLN, in the "near-optimal set" claim, and in an over-read Monte Carlo sentence. No critical issue.

## Issues

### 1. [major, statement only] Thm "Exact estimation", candidate sets for the lower part have the wrong sign
Location: statement of Theorem (thm:exact): "omega^+- in {D_s} U {alpha x_t - e^+-} U {0, omega-bar}".
Problem: the lower saturation level is omega^- = -D_s (a negative D_s) and the lower ramp/saturation hyperplane is e^- - omega^- = z_t, i.e. omega^- = e^- - z_t = |z_t - e^-| for points below e^-. The literal set {D_s} U {z_t - e^-} contains only non-positive numbers of that second kind and the wrong sign of D_s, so it cannot contain the needed values. I implemented the literal sets (signed D_s, z_t - e^- for omega^-, E as stated) and compared with the exact loss on 150 random instances: the literal sets were strictly worse in 83/150. The code is right because it uses the mirror trick (z -> -z, D -> -D, e -> -e), which the proof only alludes to ("their mirror images").
Fix: write omega^+ in {max(D_s,0)} U {z_t - e^+} U {0} and omega^- in {max(-D_s,0)} U {e^- - z_t} U {0} (or: "omega^+- in {|D_s|} U {|z_t - e^+-|} U {0}").

### 2. [minor] Thm "Exact estimation", the bound omega-bar = max|D_t| is an artificial hyperplane that leaves the stated candidate set
Location: statement and proof ("the bounds", "omega in [0, omega-bar]").
Problem: if omega^+ = omega-bar is an active face and the hyperplane e^+ + omega^+ = z_t is used, a vertex has e^+ = z_t - omega-bar, which is in E only if omega-bar equals some positive D_s. When max|D| is attained at a negative D_t this fails. The theorem is still true, but not by the vertex argument as written. Correct argument: for the upper part, replacing omega^+ by max(0, max_t D_t) never increases any residual (every prediction above max D_t >= D_t is moved towards the data, and D_t <= 0 points are unaffected for omega >= 0), so w.l.o.g. omega^+ <= max_t D_t^+, and that value is itself a D_s or 0, so the bound hyperplane is redundant. Symmetrically for omega^-. This also justifies (c) of the task: restricting to [0, max|D|] is without loss; negative D values are handled by the mirror (they bind only the lower part) and, for the upper part, only through the clip at 0 (prediction >= 0 > D_t gives a residual that is minimised by omega -> 0, which is the candidate 0).
Fix: replace omega-bar = max|D_t| by omega-bar^+ = max(0, max D_t), omega-bar^- = max(0, -min D_t) in the statement and say the bound is never active.

### 3. [minor] Proof of vertex claim is a hand-wave; the claim itself is correct
Location: proof of thm:exact, "Each hyperplane involves only ... so the coordinates of every vertex lie in the stated candidate sets."
What I verified: (i) numerically, along 150 random lines through the feasible region (e^- <= e^+, omega >= 0), including heavily tied integer data, every kink of the objective lies on one of the listed hyperplanes (e^+ = z_t, e^+ + omega^+ = z_t, e^+ = z_t - D_t, omega^+ = D_s, mirrored versions, e^- = e^+, omega >= 0); no switching hyperplane is missing (min(z-e, omega) switch, residual sign flips in ramp and saturated regions, ties at z = e are all covered; residual sign in the dead zone is the constant sign of D_t and creates no hyperplane). (ii) By hand: on the feasible region e^- <= e^+ the upper and lower clips are never both non-zero, so the objective is a sum of an (e^+, omega^+) part, an (e^-, omega^-) part, and constants; the coupling is only through e^- <= e^+ and through which points are in the dead zone, which depends on e^+ and e^- separately. A vertex is 4 independent hyperplanes. Its e-coordinates are fixed either by a direct hyperplane (z_t or z_t - D_t), or by omega fixed at D_s/0 together with e + omega = z_t (so e = z_t - D_s), or by copying through e^- = e^+. Two e + omega hyperplanes are parallel and cannot both be used. Hence every vertex e is in E (apart from bound hyperplanes, Issue 2) and omega is in the sets of Issue 1. The paper should include this three-case argument; it is the only non-trivial step, and the coupling hyperplane e^- = e^+ (which the task asked about) is harmless exactly because of the copying case.
Also note the theorem says "attains its minimum at a point"; the unconstrained code needs no interval bounds for e: e^+ >= max z or e^- <= min z is equivalent to e = max z / min z, both in E.

### 4. [minor] O(T^4) count is an upper bound, loosely justified
Location: end of proof of thm:exact. |E| = O(T^2); per candidate e the omega-candidate set has O(T) elements and each evaluation touches O(T) points, so O(T^2) per e, O(T^4) in total (this is what the code does; measured wall time T = 20/40/63/100: 0.02/0.06/0.17/0.60 s, i.e. much better than T^4 in practice because numpy vectorises the inner part). The proof's sentence "O(T) candidate steps times O(T) points" is right; add "for each of the O(T^2) values of e, twice (upper and lower)". The bound can be improved to O(T^3 log T) by sorting the points per e and sweeping slopes in omega; mention as a remark, not needed. Sorting E and the prefix sums cost O(T^2 log T), dominated. The statement "O(T^4)" is therefore correct as an upper bound. The aid-series claim "T <= 63, well under a second" is confirmed (0.17 s).

### 5. [minor] "Certified search over alpha": domain of the inner minimisation must not depend on alpha
Location: thm:lip and proof.
Verified: h(z; e, omega) = clip(z - e^+, 0, omega^+) + clip(z - e^-, -omega^-, 0) is 1-Lipschitz in z for every fixed feasible (e, omega) (slope in {0, 1}; the two clips are never simultaneously sloped when e^- <= e^+). So each residual |D_t - h(alpha x_t)| changes by at most |x_t| |alpha - alpha'|, G* = inf over a fixed set of such functions is Lipschitz with L = mean|x| (numerical max slope of G*(alpha) on a 301-point grid: 0.017 against L = 1.43, consistent). The L eta / 2 bound is right (distance to the nearest grid point is at most eta/2, and G* >= min of neighbours - L eta/2). The complexity O(T^4 (alpha_max - alpha_min)/eta) is right (plus one evaluation).
Caveat: the argument needs the feasible set in (e, omega) to be the same for all alpha. That holds if e is unconstrained or boxed in e-coordinates (as in the code), but not if the paper's estimator boxes (tau, b), because e = alpha(tau +- b) then moves with alpha. State that e (not tau) is the optimisation variable. Also state that the certificate is on the loss, not on (tau, b): the paper itself shows (UK) that near-optimal losses can come with very different targets, so "certified global optimum" must not be read as a certified target.

### 6. [minor/major, claim vs code] "returns the set of targets whose loss is within a given tolerance of the optimum" (end of Sec. 4.x) and tau_set()
Location: last sentence of the exact-algorithm subsection; code tau_set.
Problem: tau_set takes the range of tau over arrangement vertices whose loss is within tolerance. The tolerance sublevel set is a polytope in each cell whose vertices include new points on {loss = threshold} that are not arrangement vertices, so the range of tau over the true near-optimal set is generally wider. Test (t7.py): on 8 random T = 12 instances, a local search maximising tau subject to loss <= 1.10 x optimum found a larger upper end than tau_set in 7/8 (differences 0.001 to 0.017, the vertex range is always an inner approximation, never an over-statement).
Fix: say "returns an inner bound on the near-optimal range", or solve two small LPs per cell (max/min tau subject to loss <= threshold), or evaluate on a refined candidate set.

### 7. [major] Consistency: ULLN citations are for iid data, not stationary ergodic
Location: proof of thm:cons step (ii), "uniform law of large numbers for stationary ergodic sequences ... \citep{rao1962,newey1994}".
Problem: to my knowledge Newey and McFadden (1994), Lemma 2.4 is stated for iid data, and Ranga Rao (1962) is likewise an iid result. The argument required here is easy to supply (pointwise ergodic theorem plus Wald/Le Cam local bracketing: for each theta the local sup over a ball of the integrand decreases to the integrand as the radius shrinks, dominated by the envelope; cover the compact set), and holds with only B1 and the continuity and envelope already shown. Because the integrand is continuous in theta for each fixed (x, D) and has an integrable envelope, this is a three-line proof.
Fix: either give that proof or cite a stationary-ergodic ULLN (for example the ergodic version of Wald's argument; Pötscher and Prucha 1989 for dependent processes); do not attribute stationary-ergodic generality to the two cited iid lemmas.

### 8. [minor] Consistency: assumptions B1-B3 need small additions (verified otherwise)
(i) Uniqueness of the L1 minimiser: verified. g(a) = E|eps + a| has g'(a) = 1 - 2 P(eps < -a) for a.e. a; with conditional median 0 and a positive density near 0, P(eps < -s) < 1/2 for every s > 0 (monotone, strict near 0), so g strictly increases for a > 0 and strictly decreases for a < 0. Then E[g_x(a(x)) - g_x(0)] = 0 iff a(x) = 0 a.s., i.e. D*_theta = D*_theta0 a.s. This also needs E|eps| < infinity (given) and the neighbourhood may depend on x.
(ii) Continuity and envelope: verified. Hoelder-1/2 follows from 1-strong convexity (adding the two inequalities F_theta(D*') - F_theta(D*) >= (D*' - D*)^2/2 and its twin gives |D*' - D*|^2 <= 2 L_F ||theta' - theta||; the paper's constant 2 sqrt(L_F ...) is valid, a smaller constant is possible). For K = 1 this is not needed: Theorem closed-form shows D* is Lipschitz in (z, e, omega) directly. Strong convexity and the bound need omega >= 0 and b >= 0 (d >= 0): add "Theta in {omega >= 0, b >= 0}" to B3. The envelope bound |D*_theta| <= sum_k max(omega_k^+, omega_k^-) is correct: stationarity gives D* = sum_k sg_k (p_k - q_k) with p_k in [0, omega_k^+], q_k in [0, omega_k^-] (edge multipliers included), so |D*| <= max(sum omega^+, sum omega^-) <= sum_k max(...). Checked by grid on 500 random K <= 4 instances with ties and zero d: no violation beyond grid resolution 1e-4. E|x| < infinity is not needed for the envelope (only for the Lipschitz certificate in alpha); harmless.
(iii) Argmin consistency for a set: valid. Q_T continuous on compact Theta so minimisers exist; uniform a.s. convergence and Q(theta-hat) <= Q_T(theta-hat) + eps <= Q_T(theta0) + eps <= Q(theta0) + 2 eps give Q(theta-hat_T) -> min Q; every limit point is in the (closed, non-empty) argmin of the continuous Q, which by (i) is Theta_I, and compactness gives dist -> 0. The null set does not depend on the choice of the minimisers.
(iv) Point identification for K = 1: correct with two clarifications. (a) "contains the four breakpoints" must read "contains them in its interior"; if a breakpoint is an endpoint of the interval, one plateau (omega^+ or omega^-) is not seen on the support and is not identified. (b) b0 = 0 (e^- = e^+): D* = clip(z - e, -omega^-, omega^+) has only two kinks (the lower-ramp / upper-ramp junction is not a kink, slope alpha on both sides) so the statement "four breakpoints" is wrong in that case, but the conclusion holds: any theta with the same function on an interval containing both kinks must have slope alpha, kinks at the same two points, both plateau values visible, and no flat dead zone between them, hence b = 0, same e. With b0 > 0 the four kinks are distinct. omega0 > 0 is needed for the ramps and plateaus to exist; mapping back: (alpha, e^+-, omega^+-) determines tau = (e^+ + e^-)/(2 alpha), b = (e^+ - e^-)/(2 alpha), w = alpha omega, beta = -1/alpha, and the map is a homeomorphism on alpha >= alpha_min > 0, so consistency transfers to (tau, b).
Fix: reword the K = 1 sentence: "x_t has a density that is positive on an open interval containing all kinks of D*_theta0 (two if b0 = 0, four otherwise)".

### 9. [minor] Gap between the theorem's estimator and the algorithm's estimator
Theorem cons is for minimisers over a fixed compact Theta. The exact algorithm minimises over unbounded e and over omega in [0, max|D_t|], a data-dependent set that grows with the noise (e.g. Laplace). The two coincide whenever the compact-Theta constraints are inactive at the minimiser, which is true with probability going to one if theta0 is interior, but the paper should say so (or project). Also the Monte Carlo fixes alpha = 1 (known), which is a restriction of Theta, not the full estimator of the theorem. Also B1 should note that x_t is exogenous to epsilon_t in the experiment (AR(1) not fed by D) while in applications the forecast x_t depends on past policy; stationarity and ergodicity of (x_t, eps_t) is then an assumption on the closed-loop system.

### 10. [minor] Monte Carlo statement is stronger than the evidence
Location: "Quadrupling T from 50 to 200 roughly halves the errors, in line with a T^{-1/2} rate".
Facts from results/consistency_mc.csv (30 replications per T; my bootstrap on the median):
ratio of median abs error T = 200 / T = 50: tau 0.53 (90% CI 0.33-0.81), b 0.44 (0.30-0.81), omega+ 0.61 (0.30-0.83), omega- 0.40 (0.24-0.62). Log-log slopes over the three sizes: -0.46, -0.59, -0.35, -0.66 (T^{-1/2} would be -0.5). The T = 100 -> 200 step is nearly flat for tau (0.023 -> 0.021) and omega+ (0.0127 -> 0.0125). Medians at T = 50 have 90% bootstrap CIs of roughly +- 30%. So the data are consistent with T^{-1/2}, and with rates from about T^{-0.3} to T^{-0.7}; they do not confirm it. Also medians understate the tails (RMSE at T = 50 is 1.5 times the median error for tau).
Fix: say "median errors fall by 40 to 60 percent from T = 50 to T = 200 for all four parameters (30 replications, so differences of that size between adjacent sample sizes are within simulation noise); this is consistent with, but does not establish, a T^{-1/2} rate." Better: 200 replications, T in {50, 100, 200, 400, 800}, report RMSE and a fitted slope with CI.

### 11. [minor] Theorem closed-form: scope statements
The theorem is for beta < 0 and omega >= 0, e^- <= e^+ (stated before the theorem, but not in the theorem; add). For direct-control goals (alpha = 1 and "D replaced by -D") the formula changes: D*(x) = -[clip(x - e^+, 0, omega^+) + clip(x - e^-, -omega^-, 0)], not the stated expression; the aid and defence applications use this case, so state it as a corollary with the signs. The proof is fine; one line to add: the first-case claim "derivative vanishes at D = omega^+ < u" needs the right-derivative check at D = omega^+ when u = omega^+ (then D* = u, still the same value), no gap.

## Verified correct

1. Closed form (Theorem closed-form): derivative of F is D - omega^+ 1[D < u] + omega^- 1[D > l]; four cases (u >= omega^+, 0 <= u < omega^+, u < 0 < l, l <= 0 with the symmetric subcases) give exactly clip(z - e^+, 0, omega^+) + clip(z - e^-, -omega^-, 0). Sign conventions (beta < 0, e^+- = c +- d, d >= 0) are consistent with g = z - D - c. The two terms are never both non-zero because the first needs u > 0, the second needs l < 0, and l >= u. Numerically: 400 random (alpha, c, d, omega) draws (including d = 0 and omega = 0) with 6 states each (2,400 comparisons against minimisation of F over a 240,001-point grid on [-12, 12]): 0 mismatches, no case with both terms non-zero.
2. Exact estimator (code/exact_k1.py solve_fixed_alpha) implements the theorem: candidate set E = {z_t - D_s} U {z_t}; omega candidates {0, omega-bar, positive D_s, z_t - e}; mirror trick for the lower part; prefix sums with ties handled through searchsorted right/left (A = sum |D| over z <= e^+, B = sum over z < e^-, so the dead zone is e^- <= z <= e^+, as the theory requires, ties z = e belong to the dead zone with prediction 0); running minimum with argmin tracking enforces e^- <= e^+. Tests (t2.py): 300 random instances, T = 3 to 8, four regimes (continuous data, heavy ties on a small integer grid, D = 0 except one entry, all D < 0), alpha in {0.7, 1, 1.3}. Compared with (a) a brute force that enumerates a larger candidate set (adds z_t + D_s, z_t +- max|D|, z_t - z_s, |D_s|, |z - e|) over all feasible (e^-, e^+) pairs and omega pairs; (b) Nelder-Mead with 10 random starts in 1/3 of the cases; (c) recomputation of the loss from the returned parameters. Result: 0 failures (code loss equals brute force to 1e-9, never above the local-search value, returned parameters feasible: e^- <= e^+, omega >= 0, and reproduce the reported loss).
3. Switching hyperplanes (t3.py): no missing hyperplane (see Issue 3 for what was tested).
4. Lipschitz constant mean|x| and the L eta/2 bound (Issue 5).
5. Consistency (i), (ii), (iii), (iv) as discussed in Issue 8; the bound |D*| <= sum max(omega+, omega-) with K = 1..4 and edge multipliers.
6. Monte Carlo script: draws, true parameters, decision noise (Laplace, conditional median zero, satisfying B2), the estimator and table values agree with results/consistency_mc.csv (medians 0.0400/0.0385/0.0204/0.0235 etc.). Minor: the AR(1) path starts at the mean rather than a stationary draw.
7. Timing claim for the aid series (T <= 63: 0.17 s).
