Firm-year capital-allocation panel built from the SEC Financial Statement Data Sets (EDGAR XBRL), quarterly files 2009q1-2024q3 as pushed to financial_statements_data_us/ (63 quarters at build time; later quarters not yet included).
Script: code/build_sec_panel.py. Selection: 10-K filings with fiscal period FY; consolidated, non-segment, USD values dated at the fiscal-year end; flows over 4 quarters, stocks at the year end; for concepts with several XBRL tags the first available tag (order listed in the script) is used; if a firm-year appears in several filings the latest filing is kept.
firm_year_panel.csv.gz: 82,523 firm-years, 13,066 firms (CIK). Share non-missing: assets 0.98, equity 0.91, net income 0.90, cash 0.86, operating cash flow 0.82, capex 0.68, revenue 0.66, buybacks 0.35, dividends 0.32, lt_debt 0.30, R&D 0.28, debt repayment 0.27, acquisitions 0.24, debt issuance 0.23.
Caution: a missing item usually means the firm did not report that tag, which can mean zero (no dividends) or a different tag; this is not resolved here. Values are as reported (no restatement or deflation).
